# craigcontreras.dev (old)

This is my first portfolio website I created in October 2021 as a sophomore in high school. I created it using 11ty, SASS, EJS, Browserify, Gulp.js, Three.js, GSAP, and Lottie. I was 15, didn't want to figure out how to use Webpack or React --- leading to this insanely archaic tech stack. But, it did teach me how to really optimize for a good Google Lighthouse score, so that's something.
